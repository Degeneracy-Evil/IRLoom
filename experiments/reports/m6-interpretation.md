# M6 首轮解读与下一步

M6.0–M6.2 pilot 已完成。扩展动作确实暴露了旧固定覆盖的损失，透明 ridge 可以在很小的查询预算下选到好代码；但强固定覆盖在 matmul 上已匹配模型，融合链默认路径也足够好。当前证据不足以推进神经架构。M6.3 按预先门槛记录为未触发。

## 最有用的比较

下表为 blind k=4 的逐输入 regret 几何均值；两列分别是连续两批独立编译/计时。1 表示找到这12条候选中的最优。完整 k=2/4/6、随机32种子范围、原始计时和费用见 [自动报告](m6-findings.md)、[数据摘要](m6-results.json)。

| 家族 | 策略 | 轮1 | 轮2 |
| --- | --- | ---: | ---: |
| matmul | 旧 fixed_m5 | 1.1326 | 1.1382 |
| matmul | 预设 fixed_spread | 1.0021 | 1.0000 |
| matmul | greedy / adaptive | 1.4651 | 1.4755 |
| matmul | ridge / ridge_feedback | 1.0021 | 1.0000 |
| reduction | 旧 fixed_m5 | 1.0990 | 1.0978 |
| reduction | ridge / ridge_feedback | 1.0389 | 1.0421 |
| pointwise_chain | fixed_m5 / static / greedy / adaptive / ridge | 1.0000 | 1.0000 |

matmul 的池内最佳低层选择在两批8个输入中分别6/8和7/8为 tile32，旧 none/tile16 四探针未覆盖它。预先选定的 tile8/tile32 四探针也找到了与 ridge 相同的最终代码，所以不能把这部分收益归因于独有的学习能力。k=2 时 ridge 的 matmul regret 仍为1.0021/1.0000，而 fixed_m5 为1.4651/1.4755，这是少探针排序的初步信号，只有两个 blind 输入，仍需新划分复核。

归约的最佳动作在两批均为7/8个输入选择 tile4；ridge 在 blind k=4 的改善只来自两个输入中的一个，另一个仍漏掉 tile4。k=6 时 ridge 达到池内最优。下一批应预先增加覆盖 tile4 的强固定参考；这属于下一轮的新协议，不能回填为本轮预注册基线。

逐元素链在四个整模板留出的输入上都以 fused-none 最快，简单静态规则已覆盖它。ridge 的 blind log RMSE 约1.86，明显差于已见模板，说明绝对延迟外推并不可靠；因候选列表包含好默认路径而达到 oracle，不能当作性能值准确预测或程序泛化的证据。融合链所有路径都保留临时分配、释放与输出copy，收益不能解释为消除了临时分配。

adaptive 的实现只依据已查询结果，包含分支再分配和 tile16 收益触发的后续动作顺序；然而本轮20个输入在 k=4/6 下，它与 greedy 的查询序列全部相同，两批均如此。条件机制存在，但这批数据没有产生额外分配效果，不能声称已测到反馈式探索优势。ridge_feedback 在 blind k=4 也与 ridge 达到相同最佳延迟，没有独立证明反馈修正的增量价值。

## 成本与样本的边界

完整两批流程190.03 s；各批 collect 94.28/94.82 s。训练与验证使用两批完整池标签，不能忽略标签采集成本：train 两批各96个候选编译、计费墙钟33.842/34.083 s；validation 两批各48个、18.064/18.244 s。blind 两批各96个、41.270/41.380 s。这里是候选编译（含反汇编审计）及校验/计时进程墙钟求和，不含全部 Python 组织开销，不能与真实工作流总墙钟混同。

模型只训练8个独立输入、两个模板；两次重复合并后96个候选标签。21个参数，NumPy 2.5.4，验证 k=4 选择 alpha=10；拟合及验证选择约5.42 ms，不包括 NumPy导入/环境启动。12候选特征提取和推理约0.10 ms/输入，决策回放和中位数查表另计，完整值保存在JSON。特征没有额外编译，训练采集并非免费。这些成本还没有在线按查询顺序执行验证。

matmul blind k=4，ridge 计费约1.557/1.567 s每输入，fixed_spread 约2.043/2.054 s；虽查询数相同，查询路径不同使真实费用不同。离线费用求和不等于可中断的等墙钟在线搜索。候选池只有12条，oracle 也只是池内最优。

10次计时中，家族全部split的单候选 MAD/median 中位数约0.17%–0.30%，最大约4.15%；最短原生计时批约1.51 ms。按冻结规范保留短批，不事后重设迭代。比如 matmul 1.0021 与1.0000的差异远小于3%保守阈值，不解释为稳定优势。两批重复不是独立主机、独立模板或频率受控实验，随机32种子也不是新增程序样本。

## 下一步

停止在这20个输入上调策略或增加网络。下一轮先冻结更多独立模板/输入与新盲测，增加覆盖 tile4/tile32 的强廉价规则，测量跨批稳定性和训练标签获取成本；若仍有搜索损失，再做可按墙钟中断的实际在线编译/测量。当前最优集中、样本只有8个训练输入/两个模板，未达到 M6.3 的最低工程门槛（20个输入、三个模板及稳定超过强基线的决策增益）。不训练 MLP、图网络、Attention 或持续神经状态，不声称跨层级表示创新。
