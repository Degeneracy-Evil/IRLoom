# V1.3：共享分层候选上下文与校准阶段价值

规划基线 `dd67c52`；E1–E3 首轮实现、验收与冻结对照已完成。旧工具链、模型、结果保持原样。本报告区分结构/数值验收、训练和真实性能，不把夹具当新 benchmark。

## E1：真实 MLIR 上的候选上下文

`v13-e1-context` 由匹配 Polygeist bridge 解析合法 MLIR：同一模块含头部/签名相同、函数体分别 add/mul 的 f/g，保留全部节点，只改变一个 call→callee 边。对种子17/23/47，旧 structured-v2 的 A/B inline q 差均为0；新 hierarchical-v3 可区分，关联 callee/body→角色→读出的梯度非零。只重命名 SSA、交换等价 DictionaryAttr 打印顺序时输出精确不变。该结果只是结构可达性，不说明应该内联哪个函数或已学会性能。

共享计算顺序固定为 typed SparseBlock 局部处理→沿 contains/defines/argument 归属自底向上内容池化→已解析 callee 与 callsite 交互/模块汇总→原 A 阶段 Block 或 B 共享 Block+GRU→角色化候选读出。CFG 环和递归调用不作为树父关系。inline 读取 callsite/caller/callee+body/region/module，unroll 读取 loop/body/所在函数；缺失角色有显式 mask，fusion 仍仅 smoke。每份函数/区域内容汇总复用，记录 summary 和 candidate-read 耗时，不创建全程序 N×N 注意力；树池化工作量还随结构深度增长，未声称任意深图常数代价。

A/B 骨干与记忆公式不变，B 写入的当前状态现在来自内容汇总；一般 lowering 仍只按既有粗锚点继承。`v13-e1-state` 通过真实分支/恢复/RNG/完整与增量编码输出比较、数值检查；`v13-e1-a-fit` 通过 A 集成拟合、跨阶段梯度和完整编译。旧表示开关及旧 checkpoint 继续保留。

## E2：log 代价目标可同时满足

`v13-e2-objective` 使用实际 Torch 目标复现两标签数学诊断：真间距 log(1.09) 时，旧 softplus 在真 q 处仍有梯度，拟合间距0.734565、隐含比2.084575；有限实测 margin 与纯区间回归均拟合0.0861777、比1.09，真值处 loss/梯度为0。相同产物零代价、near-tie 和原真实训练子集也通过可行性检查。这是数值语义验收，不是编译性能。

新 `calibrated-margin-v1` 使用有限 `relu(max(0,|yi-yj|-mi-mj)-sign(yi-yj)*(qi-qj))²`，保留旧 `softplus-v1` 和 `interval-only-v1`。新实验统一将毫秒分辨率分别经 numerator/denominator 传播到 log 比值区间；不用毫秒阈值直接当 log margin。误差区间仍是冻结分辨率规则，不称统计置信概率。q 语义仍是根默认归一化、后续 all-advance-v1，不是 Q*。

## E3：冻结结构覆盖与最小消融

`pilot-v1-3.json` 在新阶段标签前冻结：固定种子按动作种类、所属函数、循环层次和 callee 分层抽样；小池全覆盖，大池轮转抽样而非固定首尾。每个程序采三个真实 S0 选择产生的 S1 前缀，每观察点最多六动作、包含 advance，每程序最多25个完整标签产物。标签产物冻结后，根默认和所有候选做六轮随机/反向配对交错，根默认共用同一参照；初次编译测量也计费但不冒充最后标签。

训练 PC1/lists，验证新 matrix，Perlin 为预先冻结的新测试族，旧 DES/Puzzle 仅诊断。新增程序均使用原始官方 test-suite 源码，Perlin 用原有 SMALL_PROBLEM_SIZE 宏控制成本，不改算法；来源/许可证见 `programs-v1-3.json`。methcall 前端崩溃和 Treesort 的导入错误保留于 v13-import-1/2，不通过改算法掩盖。没有按模型效果挑程序或调低噪声阈值。

最小矩阵：同旧表示比较旧/新损失(A/B)，同新损失比较旧/分层表示(A/B)，最后在分层输入上比较独立训练无连续记忆 A/B；仅一个预先固定种子23。冻结断连为补充，raw/guarded 控制器与预算沿用 V1.2。新增摘要/读出带来参数差异，不能直接将共同表示收益算连续记忆收益。

实际采集 49 个匹配动作终端（PC1 12、lists 15、matrix 22），另有六个根默认。训练8个前缀组、验证4组；根默认/候选的最终标签计时共312次，加初次构建/验证阶段275次，总原生计时587次，全部计费，采集60.723秒，零失败。PC1 S0 产生8对超过门槛的排序，lists 与训练S1仍无可分辨效果；matrix验证的一条S1前缀出现一个可分辨有害动作，形成5个成对标签。扩大结构覆盖并未补齐有害动作训练样本，不能将8对称作8个独立程序。

八套对照均完成20次更新。验证有一组可分辨，但最小候选 regret 多轮并列为0，按预注册“最早并列点、不用回归破平”全部保存第0轮（0-based）。因此部署 checkpoint 只经历一次更新，不能将最后训练轮的校准误差冒充其实际质量。最终同时列保存点与末轮指标；这也是当前验证集分辨能力的限制，没有用 Perlin/DES/Puzzle 换 checkpoint。

结构抽样数据审计的首次断言把 JSON 中的 list 与 Python tuple 直接比较而失败，规范序列化后按相同 seed 重建选择通过；没有更改数据或抽样方案。原日志保留，`v13-data-audit-2` 另存正式覆盖/复现检查。

MAE/偏置为根归一化 log 代价量，非概率；相对误差为 |exp(q−y)−1|。有害误判率按有害动作被预测优于 advance 统计，不能把单一有害标签当稳定泛化估计。验证选择仍以候选 regret 为主，MAE 未用于打破冻结并列规则；最后一轮更低误差不意味着选用其产物。

目标可达模块数扣除旧 policy/value/resource 和 A 未受 q 监督的 S2 Block；共享摘要在决策阶段受训，完整 Embedding 表仍计入。这不等于逐元素非零梯度数或独立物理内存。新上下文增加参数/计算，表示对照不是严格容量匹配，不能把参数或共同摘要的效果算作跨阶段记忆收益。

采集 60.723 秒（含所有初次验证与交错标签），训练 155.218 秒，raw/guarded 编译/选择/确认 546.826 秒，最终交错 66.575 秒。加载/特征/summary/candidate-read/network 原始计费均记录，summary与candidate-read是父项中的子计时，不能重复相加。完整包装器成本在 logs/architecture/entry-*.json，Torch模型峰值内存未独立测量，原生RSS在原始timer记录；目标文件字节不是纯.text大小。

本轮修复的结构传播路径与 q 数值可行性有直接验收证据，但不保证它们解释全部性能负例。后续优先扩充独立完整程序、真正可分辨的多阶段有害/有益标签及更能区分 checkpoint 的验证组；不据新测试效果更改本轮模型/阈值/划分，也不另起 PGO、RL 或新骨干研究线。

### 最终验收与结果边界

Perlin 新测试族的分层 A/B raw 为 0.99935/1.00001×，没有可分辨加速；二者 raw 及所有 guarded Perlin 产物均与默认逐字节相同，微小差异只能描述计时波动。默认中位数59.2166 ms，native Clang -O3 配对比0.9897×。部分其它 raw 配置虽字节不同，时间仍接近1×，不据此宣称收益。

保存点的校准没有普遍改善；末轮 one-hop B 的 MAE 从旧损失0.04337降至有限margin的0.02206，但这不是被部署的checkpoint，也不是完整程序收益。分层A保存点MAE约0.625、末轮0.0945，提醒结构可达性与损失可行性并不保证已训练好模型。验证matrix的默认完整进程约0.807 ms、包含启动；唯一超过冻结分辨率的有害候选不等于统计显著性，且候选regret并列不足以区分校准质量。未因此换权重、增轮数、换测试或降低门槛。

`v13-final-acceptance` 重算八套保存权重的完整验证指标并核对并列选择；120次编译/搜索全部正确、无未完成确认或超预算，1800次搜索计时和1320次冻结计时、反向配对顺序及产物等价组均通过检查。A/B 新进程重新导入完整 Perlin 后，除本应不同的会话/快照身份，结构输入、候选、q/辅助浮点输出、排名和动作精确一致；复用 `--v13 all --name v13-stage` 后原始dataset/training/evaluation/计时报告逐字节不变，成本没有被缓存短耗时覆盖。

硬件/工具链和原始路径见JSON：Intel Xeon 6986P-C，Linux6.8/glibc2.39；编译及原生程序固定CPU0，Torch单线程，未控制频率/其它负载。模型加载字段为常驻Torch进程内加载，非冷Python启动；各Torch模型峰值内存未独立测量，原生RSS仍保存在原始timer数据。

复现：`bash scripts/architecture.sh --v13 all --name my-v13`；结构与数值验收分别用同入口的 `--context-audit`、`--objective-audit`。详见[运行指南](../../docs/architecture/RUNNING.md)。本轮不将默认保护、共享摘要/头、初始权重或额外参数的效果算作连续记忆贡献；旧结果和所有不利指标完整保留。
