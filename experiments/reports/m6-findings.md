# M6 首轮：扩展覆盖、反馈式探针与可学习性能 pilot

本轮为离线回放。固定覆盖、真正依据已测反馈分配后续查询、透明 ridge 模型分开比较。不把查询次数预算声称为墙钟预算，也不声称已部署在线优化器。

## 数据与预先划分

- 批次1：`logs/20261018T171911048006Z/records.jsonl`；commit `7f0b1e0107d250aab44d37ae84ea587b18f86063`；工作区干净；240/240 正确；2400 样本；全池墙钟 94.28 s。
- 批次2：`logs/20261018T172045377274Z/records.jsonl`；commit `7f0b1e0107d250aab44d37ae84ea587b18f86063`；工作区干净；240/240 正确；2400 样本；全池墙钟 94.82 s。

候选为 A0/A1 × none/tile4/tile8/tile16/tile32/unroll4，12 条；参数和 Shape 在正式采集前冻结。训练 8 个实例（matmul/归约各4），验证4个实例（各2），盲测8个实例（各2个未见 Shape，加4个整模板留出的逐元素链）。两次计时属于同一个 case 的同一 split，训练标签为合并重复的中位延迟，不能当作独立实例。

逐元素链 C=A*B+A 使用两个 linalg.generic；A0 保持两阶段、A1 合法融合为一阶段，与归约/三重 matmul 有不同计算结构。one-shot bufferization 后两路均有一个临时 alloc/dealloc，输出 copy 和临时申请释放包含在 kernel 延迟中。单核、固定批次次数、10次计时、四个正确性种子、热态复用保持一致。

## 模型与可见信息

Ridge 参数 21 个（含截距），NumPy 2.5.4；alpha 从 [0.1,1,10] 仅按验证集 k=4 的 regret 选为 10.0；归一化仅在训练集拟合。本次拟合/验证选择共 0.0054 s，训练日志见 m6-model.json 和本机 training.json。

特征仅来自输入结构、Shape、计划高/低层动作和静态目标 cache：操作量、字节量、归约范围、预期最内层 stride/extent、tile 参数与边界余数等；无需额外 Lowering，未读取未来 LLVM IR、代码或未查询路径延迟。特征生成只作纯数值计算，额外编译次数为零。模型/特征 schema 和精确 split 已在采集前提交；模型文件在首次盲测评分之前保存。盲测为预先留出标签，不是外部保密评审。

## 策略与真实成本

fixed_m5 保留 none/tile16/unroll4 的跨分支顺序；fixed_spread 预先用 tile8/tile32/none。static 使用冻结 Shape/连续访问规则；greedy 先两个 none 然后固定分支。adaptive 先两个 none，用已测最优和分支探针数的乐观界选下一分支，且依据实际 tile16 收益改变后续 tile/unroll 次序。其查询在反馈后变化，区别于固定均衡覆盖。

ridge 只按冻结预测分配候选；ridge_feedback 先两个 none，再以同分支已测 log-residual 修正未测预测。random/stratified_random 各32种子，抽取唯一候选；oracle 只事后计分。k=2/4/6 时，各方法均 k 次候选编译、4k 次 correctness、10k 次 timing、零校准，同一 case 的原生 kernel 调用次数严格一致。JSON 保留编译/校验/采样真实费用离线求和、推理与决策开销。

## 辅助预测分数与测量噪声

固定迭代可能产生不足10ms的短批次；保留样本，不为改善结果事后增加迭代。小于 max(3%, 三倍两候选最大相对MAD) 的成对差异不解释为稳定增益；两批重复仍不能消除频率漂移或共享负载。

本轮只有8个训练输入实例、两个训练模板；整条融合链未参与训练/调参。低参数拟合的候选标签仍来自少数相关程序，所有结果仅是 pilot。在预先门槛（至少20个训练实例、3个训练模板，并有稳定同预算决策增益）满足前，不执行 M6.3。本轮没有 MLP、图模型、Attention 或持续神经状态，也没有参数量匹配的跨层级神经消融；记录为未触发，不宣称架构创新。

若 cheap fixed/random 在某家族已逼近 oracle，应保留负结果并优先改进基线。即使 RMSE 改善，决策 regret 不改善仍不算成功；模型可见训练/验证标签和可见探针反馈，不能用盲测成绩回调参数。

## 复现

```bash
bash scripts/phase0.sh m6
```

单入口两批独立重编译→仅 train/validation 拟合→保存冻结模型→首次 blind 回放和报告。所有完整命令/IR/二进制在 logs/ 与 tmp/；公开摘要含原始计时、成本、特征、随机分布和查询样例。模型训练与推理只增加 NumPy 数值求解，无额外 MLIR 探针；依然不计算 hash、不写单元测试。共享负载/频率不可控、同主机连续两批、随机种子不是独立程序，不能声称硬件泛化或实际在线等墙钟收益。
